You are building **Dissolve**, a personal app for iPhone and Mac: habit tracking, a GitHub-style consistency grid, countdowns, a "life in weeks" graph, a daily journal with templates and images, and statistics. **Every feature has widgets.**

It is for one person (me) and will never be on the App Store. **I use a free Apple account (no $99 Developer Program).** That rules out CloudKit, push notifications and TestFlight, and every decision below follows from it.

## 3. Features (requirements)

### 3.1 Habits
- **Types:**
  - binary (done / not done);
  - quantity (target + unit, e.g. 8 glasses; partial progress counts);
  - timed (minutes; later milestone);
  - limit (e.g. ≤ 2 coffees — success means staying under).
- **Schedules:** daily · specific weekdays · X times per week · every N days.
- **Day status:** completed · partial · skipped (planned rest — neutral for streaks) · missed · not scheduled.
- **Streak:** consecutive *scheduled* days completed. Skipped days neither break nor extend it. Weekly-frequency habits count streaks in weeks. An "X per week" habit doesn't break while the weekly target is still reachable.
- **Strength score:** Loop-style exponential smoothing, so recent days weigh more and one miss doesn't erase a long run. Show it next to the streak.
- **Dates:**
  - Store logs against a **local calendar date** (year-month-day), not a timestamp.
  - A setting "day ends at" (default 4 am) decides which day a late check-off counts for.
- Past days are editable without limit.
- Schedule changes take effect from a date, so old history is never recalculated.
- Archived habits leave Today and the widgets, but keep their history.
- One log record per habit per day.

### 3.2 Consistency grid (most important feature — make it beautiful)
- **Per-habit grid:** GitHub-style year view of 53 week columns × 7 weekday rows, with:
  - today at the right edge;
  - month labels;
  - a Less–More legend.
- **Overall grid:** same layout, shaded by the share of scheduled habits completed that day. A toggle also counts "journaled today".
- **Shading levels:**

  | Level | Goal completion | Colour |
  |---|---|---|
  | 0 | none | system fill |
  | 1 | 1–33% | habit colour at 30% opacity |
  | 2 | 34–66% | habit colour at 50% opacity |
  | 3 | 67–99% | habit colour at 75% opacity |
  | 4 | 100%+ | habit colour at 100% opacity |

  Skipped days show as an outlined cell.
- Build the grid from **custom SwiftUI cells** (not Swift Charts), so cells support tap and hover, animations and per-day accessibility labels.
- Tap or hover a cell → popover with the date, value and note. Tap again → edit that day.

### 3.3 Countdowns
- **Fields:** title, SF Symbol, colour, optional photo, target date or date-and-time.
- **Display:** days · weeks + days · live D:H:M:S. Plus a progress ring measured from the creation date.
- Also support:
  - count-up mode ("days since");
  - yearly repeats (birthdays);
  - a celebration, then auto-archive, when the date arrives.

### 3.4 Life graph
- **Inputs:** date of birth and lifespan (default 90 years); optional life "eras" shown as coloured bands.
- **Layout:** "Life in Weeks" — 90 rows × 52 columns = 4,680 cells.
  - Past weeks filled, the current week pulsing, future weeks outlined.
  - Each row starts on a birthday.
  - Draw it with **`Canvas`** for performance.
- Headline, e.g. "1,612 weeks lived · 3,068 remain (65.6%)".
- Later: tint each past week by that week's consistency.

### 3.5 Journal with templates and images
- A **Template** is an ordered list of **blocks**:
  `heading | prompt | text | checklist | image | mood | rating | habitSummary`.
  Templates can contain images.
- Creating a day's entry **copies** the template's blocks into the entry. Later edits to the template never change past entries.
- One entry per calendar day (enforce it in code).
- Each entry has: mood (1–5), cached word count, and a link to the template it came from.
- **Images:**
  - pick several with `PhotosPicker`; on Mac, also drag-and-drop and paste;
  - resize to about 2,048 px on the long edge, save as HEIC;
  - store a separate small thumbnail.
- **Privacy:** Face ID / Touch ID lock on the journal; blurred content in the app switcher.
- **MVP:** one default template with prompt, text, image and mood blocks.
- **Later:**
  - templates per weekday;
  - checklist and rating blocks;
  - "On this day".

### 3.6 Statistics
Each card leads with a plain one-sentence insight, Apple Health style, then the chart.
1. Strength score per habit and overall, with 30 / 90 / 365-day trends.
2. Completion rate (completed ÷ scheduled; skipped days excluded) by week and month.
3. Current and best streak.
4. Completion by weekday.
5. Journal: entries per month, journaling streak, average words, mood trend.
6. Later, after ~30 days of data: mood on habit days vs non-habit days, and habit co-occurrence. Label these as patterns, not causes.

## 5. Sync without CloudKit (iCloud Drive folder + per-device change logs)

- **Folder setup:**
  - On first launch, each device asks me to pick the same folder in my iCloud Drive (iOS: `UIDocumentPickerViewController` for folders; macOS: `NSOpenPanel`).
  - Save a **security-scoped bookmark** to it.
  - macOS needs the App Sandbox entitlement plus `com.apple.security.files.user-selected.read-write`. Don't add any iCloud entitlement.
- **Each device writes only its own files:** `changes/<deviceID>/<yyyy-MM>.jsonl`. Each line is one change: `{entity, id, updatedAt, deleted, fields}`.
- **Merging:**
  - Merge on app launch, on returning to the foreground, and in a `BGAppRefreshTask`.
  - Read the other devices' new lines from a saved offset.
  - Per record, the newest `updatedAt` wins.
  - Deletes are tombstones.
  - Then reload the widgets.
- **Photos:** `photos/<uuid>.heic` + `photos/<uuid>_thumb.heic`. Write once, never modify.
- **Housekeeping:**
  - Use `NSFileCoordinator` for all reads and writes.
  - Call `FileManager.startDownloadingUbiquitousItem(at:)` for files iCloud has offloaded.
  - Each month, write a snapshot and compact old logs.
- **Tests:** unit-test the merge logic, including two devices editing the same day, deletes and clock differences.
- **If this fails in Milestone 0:** tell me. The options are a Supabase free project (500 MB database, 1 GB files, pauses after a week idle) or device-only storage with manual export/import. I'll choose.
- Also build **"Export everything"**: JSON + one Markdown file per journal entry + images, zipped, via `fileExporter`.

## 7. Visual design — must feel like an Apple app

- **Liquid Glass:**
  - Use standard containers so it comes automatically: `TabView` on iPhone, `NavigationSplitView` on Mac, plus standard toolbars and sheets.
  - Add custom `.glassEffect()` to only 1–3 floating controls: the Today "Journal today" pill, the grid range picker and the journal formatting bar.
  - Group them in a `GlassEffectContainer` and morph with `glassEffectID`.
  - Content cards are **solid**, not glass: `.background(.background.secondary, in: .rect(cornerRadius: 22))`.
- **Motion:**

  | Effect | API | Where |
  |---|---|---|
  | Natural motion | `.snappy` (taps), `.smooth` (layout) | Every state change; never linear |
  | Rolling numbers | `.contentTransition(.numericText(value:))` | All changing numbers |
  | Haptics | `.sensoryFeedback(.success, trigger:)` | Completing a habit; `.increase` on +1 |
  | Living symbols | SF Symbols Draw On / Variable Draw / `.symbolEffect(.bounce)` | Checkmark draws itself; quantity symbol fills |
  | Celebration | `PhaseAnimator` / `KeyframeAnimator` | When the day reaches 100%; under 1.2 s |
  | Hero transitions | `.navigationTransition(.zoom)` + `.matchedTransitionSource` | Habit card → detail; countdown tile → full screen |
  | Shared elements | `matchedGeometryEffect` | Grid cell → day popover |
  | Scroll polish | `.scrollTransition` | Card lists |
  | Living backgrounds | `MeshGradient` | Countdown and Life headers |

  Grid columns fill left to right on appear (small stagger), and today's cell pulses gently. Respect Reduce Motion by switching to crossfades.
- **Colour:** system colours only. App accent: green. Each habit picks from ~12 system colours.
- **Type:** text styles only (Dynamic Type). Numbers use `.fontDesign(.rounded)` + `.monospacedDigit()`.
- **Spacing:** 4-pt grid; margins of 16 pt (iPhone) and 20 pt (Mac); card padding 20; continuous corner radius 20–24.
- **Accessibility:** VoiceOver labels on every grid cell, e.g. "March 3, 2 of 3 habits".
- **Previews:** every view gets a SwiftUI Preview with seeded in-memory data.

### Screens

## 8. Data models (starting point — refine as needed)

- `Habit`: id, name, symbol, colorName, type, target, unit, sortOrder, archivedAt, createdAt
- `HabitSchedule`: habit, kind, weekdays, timesPerWeek, everyNDays, effectiveFrom
- `HabitLog`: id, habit, date (`yyyy-MM-dd`), value, status, note, updatedAt
- `Countdown`: id, title, symbol, colorName, targetDate, isAllDay, createdAt, repeatsYearly, countUp, photoID, archivedAt
- `LifeProfile`: birthDate, lifespanYears, eras
- `JournalTemplate` → `[TemplateBlock]` (kind, order, promptText, placeholder, imageID, required)
- `JournalEntry`: id, date, mood, wordCount, templateID → `[EntryBlock]` (kind, order, promptText, text, checklist, rating, photoIDs)
- `Photo`: id, fileName, thumbFileName, width, height, caption, createdAt

Every model also has `id: UUID` and `updatedAt: Date`, which the sync layer uses.
